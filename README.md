# Sistema Simples de Controle de Tarefas Administrativas

**Projeto Integrador – Laboratório de Programação**

**Instituição:** Universidade Santo Amaro (UNISA)  
**Curso:** Análise e Desenvolvimento de Sistemas  
**Professora/Professor orientador:** Prof. Patrick Anderson Matias de Araujo  
**Linguagem utilizada:** Python

## 1. Sobre o projeto

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso de Análise e Desenvolvimento de Sistemas da Universidade Santo Amaro (UNISA).

O objetivo é apresentar uma solução simples para auxiliar na organização de tarefas administrativas em pequenos escritórios, aplicando conceitos fundamentais de lógica de programação e estruturas de dados.

## 2. Funcionalidades

O sistema possui quatro funcionalidades principais:

1. **Cadastrar tarefa:** permite registrar uma nova atividade.
2. **Visualizar tarefas:** apresenta as atividades cadastradas e seus respectivos status.
3. **Concluir tarefa:** permite marcar uma atividade como concluída.
4. **Sair:** encerra a execução do programa.

O sistema também realiza verificações básicas para impedir o cadastro de tarefas vazias e tratar opções inválidas.

## 3. Tecnologias e conceitos utilizados

- Linguagem Python.
- Ambiente de desenvolvimento IDLE.
- Variáveis e listas.
- Estruturas condicionais (`if`, `elif` e `else`).
- Estruturas de repetição (`while` e `for`).
- Comandos de entrada e saída (`input` e `print`).

## 4. Como executar o programa

Para utilizar o sistema, é necessário ter o Python instalado no computador.

1. Acesse este repositório no GitHub.
2. Baixe o arquivo `controle_tarefas.py`.
3. Abra o arquivo utilizando o IDLE do Python.
4. Pressione a tecla **F5** para executar o programa.
5. Escolha uma das opções apresentadas no menu.

Também é possível executar o programa pelo terminal utilizando o comando:

```bash
python controle_tarefas.py
```

## 5. Limitações do sistema

As tarefas são armazenadas temporariamente na memória do programa. Portanto, ao encerrar a execução, as informações cadastradas não são preservadas.

Como melhoria futura, poderá ser implementado um recurso para salvar e recuperar as tarefas, além de funcionalidades como edição de atividades, definição de prioridades e inclusão de prazos.

## 6. Finalidade acadêmica

O projeto tem finalidade educacional e demonstra a aplicação prática dos conhecimentos introdutórios de programação na resolução de necessidades administrativas.
